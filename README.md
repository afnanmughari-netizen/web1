# Leon Template - موقع ويب تعريفي (Landing Page)

مشروع تصميم وتطوير صفحة ويب عصرية متكاملة تم بناؤها باستخدام لغة **HTML** وتنسيقات **CSS**، تطبيقاً لمتطلبات مادة تطوير الويب.

---

##  مميزات الكود والصفحة
- **تنظيم وهيكلية الكود:** استخدام وسوم HTML5 الدلالية (Semantic Tags) مع تنظيم المسافات والترتيب لسهولة القراءة.
- **التوثيق والتعليقات:** تم تزويد الكود بتعليقات توضيحية (`<!-- Comments -->`) توضح بداية ونهاية كل قسم لتسهيل التعديل والصيانة.
- **تضمين مكتبات خارجية:** 
  - خطوط Google Fonts لتنسيق النصوص بشكل احترافي.
  - مكتبة أيقونات Font Awesome لإضافة أيقونات تفاعلية للأقسام.

---

##  أقسام الصفحة (Sections)

1. **الترويسة (Header):**
   - يحتوي على شعار الموقع (Logo).
   - قائمة تنقل (Navigation Bar) تتضمن روابط سريعة للأقسام الرئيسية مع أيقونة الـ Menu.

2. **الواجهة الترحيبية (Landing Section):**
   - واجهة بسيطة وجذابة تستقبل الزائر بعبارات ترحيبية.

3. **المميزات (Features):**
   - استعراض لأبرز 3 ميزات وخدمات يقدمها الموقع مدعومة بأيقونات ونصوص وصفية.

4. **الخدمات (Services):**
   - استعراض مجالات العمل مثل: (Graphic Design, UI/UX, Web Design, Web Development) ومقسّمة داخل أعمدة منظمة مع صورة توضيحية.

5. **معرض الأعمال (Portfolio):**
   - عرض للمشاريع المنجزة مع صور توضيحية ونبذة مختصرة عن كل مشروع.

6. **من نحن (About):**
   - قسم تعريفي يحتوي على صورة وفقرات نصية تشرح هوية وأهداف الفريق/الشركة.

7. **التواصل (Contact Us):**
   - يحتوي على عنوان البريد الإلكتروني للتواصل وروابط حسابات التواصل الاجتماعي (Facebook, X, Google).
